# SHIFT UP and Stellar Blade: Console-to-PC Financial Analysis

시프트업의 콘솔 진출작 `스텔라 블레이드`가 PS5 출시, PC 확장, 장기 판매로
이어지는 동안 매출 구조와 수익성, 현금흐름이 어떻게 변했는지 분석한
데이터셋입니다. 금액은 연결 기준 원화입니다.

## 범위

- SHIFT UP (KOSPI 462870, Open DART corp code 01384787)
- 2025년 사업보고서와 2026년 1분기보고서의 연결재무제표
- 2024년 1분기부터 2026년 1분기까지의 IP별 분기 매출
- PS5 출시(2024-04-26), PC 출시(2025-06-12) 전후 비교

## 핵심 결론

### 1. 콘솔 성공보다 멀티플랫폼 재출시의 재무효과가 더 컸다

`스텔라 블레이드` 매출은 2024년 681억원에서 2025년 1,176억원으로
72.8% 증가했고, 전사 매출 비중도 30.4%에서 39.9%로 상승했습니다.
PS5 출시 분기인 2024년 2분기 IP 매출은 259억원이었지만 PC 출시 분기인
2025년 2분기에는 657억원을 기록했습니다. 후자는 기존 PS5 매출도 포함하므로
순수 PC 매출과 같지는 않지만, 플랫폼 확장의 규모를 보여주는 유용한
이벤트 지표입니다.

PC판은 출시 3일 만에 100만 장, 전 플랫폼 누적 300만 장을 돌파했습니다.
패키지 판매량과 회계상 영업수익은 퍼블리셔 정산, 환율, 수수료 및 수익인식
시점이 달라 직접 나누어 평균판매가격을 계산해서는 안 됩니다.

### 2. 매출 성장의 대부분을 스텔라 블레이드가 만들었다

2025년 전사 매출은 전년보다 705억원 증가했습니다. 이 가운데
`스텔라 블레이드` 증가액이 495억원으로 70.3%를 차지했고, `니케`는
138억원, 기타는 71억원을 더했습니다. 이에 따라 모바일 라이브서비스 IP
한 작품에 의존하던 구조가 모바일과 PC·콘솔의 두 축으로 바뀌었습니다.

### 3. 이익은 늘었지만 플랫폼 수수료로 마진은 낮아졌다

2025년 매출은 31.4% 증가했지만 영업이익은 18.8% 증가하는 데 그쳤습니다.
영업이익률은 68.1%에서 61.6%로 6.5%p 하락했습니다. 같은 기간 영업비용은
714억원에서 1,131억원으로 늘었고, 회사 IR상 변동비는 74억원에서
431억원으로 482.5% 증가했습니다. 회사는 이 변동비를 거래 수수료 등으로
설명하며, 사업보고서도 2025년 말 유동부채 증가 원인 중 하나로
`스텔라 블레이드` PC 관련 수수료를 명시합니다.

그럼에도 2025년 증가 매출 705억원에서 증가 영업이익 287억원이 발생해
증분 영업이익률은 40.8%였습니다. 절대 이익 증가라는 관점에서는 성공적이지만,
콘솔·PC 패키지 매출을 수수료 없는 고마진 매출로 보면 안 됩니다.

### 4. 후속작 투자가 진행되면서 단기 마진은 더 낮아졌다

2026년 1분기 `스텔라 블레이드` 매출은 전년 동기보다 84.0% 증가한
129억원이었고 전사 매출도 12.0% 증가했습니다. 그러나 영업비용이 61.4%
늘면서 영업이익은 18.1% 감소하고 영업이익률은 62.2%에서 45.5%로
낮아졌습니다.

같은 분기 연구개발비는 169억원으로 매출의 35.65%였으며 전액 비용 처리됐습니다.
2025년 연간 연구개발비도 651억원으로 전년보다 127.8% 증가했습니다.
따라서 현재 마진 하락은 기존 타이틀의 실패라기보다 후속작과 신규 프로젝트를
위한 비용 선행 성격이 강합니다. 다만 연구개발비가 타이틀별로 공시되지 않아
얼마가 `스텔라 블레이드` 후속작에 투입됐는지는 알 수 없습니다.

### 5. 순이익보다 영업이익을 봐야 한다

2026년 1분기 순이익은 378억원으로 40.8% 증가해 영업이익 215억원보다
컸습니다. 회사 IR은 환율 변동 관련 이익과 자금운용수익을 주요 원인으로
설명합니다. 이는 게임 판매의 수익성 지표가 아니므로 성장성 판단에는
영업이익과 IP별 매출을 우선해야 합니다.

### 6. 차기 AAA 개발을 감당할 재무여력은 충분하다

2026년 1분기 말 현금 및 현금성자산은 1,590억원이고, 이를 포함한 유동
금융자산은 약 6,947억원입니다. 부채비율은 14.4%, 유동비율은 1,124.7%로
매우 보수적입니다. 2025년 간이 FCF는 1,546억원, 2026년 1분기는 720억원입니다.
간이 FCF는 `영업활동현금흐름 - 유형자산 취득 - 무형자산 취득`으로 계산했으며,
분기 현금흐름은 매출채권 회수와 운전자본 변동 때문에 연율화하면 안 됩니다.

## 다음 성장 구간과 위험

- 기존작: 회사는 2026년 내 Nintendo Switch 2 버전 출시를 확정했습니다.
  PS5에서 PC로 확장했을 때처럼 신규 이용자층을 여는 세 번째 플랫폼입니다.
- 후속작: `스텔라 블레이드` 차기작은 개발 중이며 회사는 직접 퍼블리싱하는
  first-party service 모델을 계획하고 있습니다. 성공하면 경제적 몫과 고객
  데이터 통제력이 커질 수 있지만, 마케팅·유통비와 실행 위험도 회사가 더
  부담합니다.
- 집중도: 2025년 `니케`와 `스텔라 블레이드`가 매출의 96.1%를 차지합니다.
  두 IP 중 하나의 공백이 커지면 실적 변동성이 높아집니다.
- 출시 주기: 2025년 2분기 `스텔라 블레이드` 비중은 58.5%였지만 2026년
  1분기는 27.3%입니다. 패키지 게임의 출시 피크와 롱테일을 구분해야 합니다.

## 파일

- `dataset/companies.csv`: 회사와 DART 식별자
- `dataset/financial_accounts.csv`: 전체 연결재무제표 계정
- `dataset/financial_highlights_long.csv`: DART 주요계정
- `dataset/disclosures_2026.csv`: 수집한 정기공시 목록
- `dataset/provenance.json`: 수집 범위와 행 수
- `analysis/title_revenue_quarterly.csv`: 분기별 IP 매출과 플랫폼 이벤트
- `analysis/financial_summary.csv`: 수익성, 현금흐름, 연구개발 및 안정성 요약

## 계산 정의와 주의점

- 영업이익률: 영업이익 / 영업수익
- 부채비율: 부채총계 / 자본총계
- 유동비율: 유동자산 / 유동부채
- 간이 FCF: 영업활동현금흐름 - 유형자산 취득 - 무형자산 취득
- 증분 영업이익률: 전년 대비 영업이익 증가액 / 전년 대비 매출 증가액
- IP별 매출에는 플랫폼별 상세 분리가 없으므로 PS5와 PC의 개별 매출 또는
  개별 마진은 계산할 수 없습니다.
- 2024년 분기별 IP 매출은 회사 4Q 2025 factsheet, 2025년 이후는 회사
  1Q 2026 factsheet를 사용했습니다. 연간 및 2026년 1분기 재무제표는
  최종 Open DART 공시를 우선했습니다.

## 재수집

```bash
export OPENDART_API_KEY="발급받은_40자리_인증키"

python3 collect_dart.py \
  --companies config/console_game_companies.json \
  --output dart_data/console_games \
  --start-date 20260101 \
  --end-date 20260727 \
  --disclosure-type A \
  --download-originals

python3 collect_financial_data.py \
  --companies config/console_game_companies.json \
  --raw-root dart_data/console_games/financial_api \
  --dataset-dir console_games/dataset \
  --disclosure-catalog dart_data/console_games/disclosures.jsonl \
  --refresh
```
